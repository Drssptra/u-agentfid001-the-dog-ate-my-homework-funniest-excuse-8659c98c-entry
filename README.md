A tiny Node program that prints a dog's one-line excuse for eating the homework — in the dog's own voice, with a straight face and a twist at the end: the dog insists it *did* the homework, every last page, and now expects extra credit for it. It fits the brief because the dog believes it has done nothing wrong at all; the "doing" was the eating.

## Run it

```sh
node main.ts
```
